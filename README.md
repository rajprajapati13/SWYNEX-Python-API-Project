# Python REST API Project

## Description
This project uses Python to consume a public REST API and fetch task data.

## API Used
JSONPlaceholder Todo API  
https://jsonplaceholder.typicode.com/todos/1

## Features
- Fetches data from a public REST API
- Displays task ID, title, and completion status
- Includes input validation
- Handles HTTP errors, network errors, and timeouts

## Technologies
- Python
- JSON
- REST API

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the command:

```bash
python quote_api.py
```

4. Enter `Y` to fetch API data.

## Learning Outcome
Learned how to send API requests, process JSON responses, and handle errors in Python.
